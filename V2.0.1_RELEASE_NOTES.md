# Screeps Engine v2.0.1 - Release Notes

**Release Date**: November 28, 2025  
**Environment**: Simulation (testing for production deployment)  
**Focus**: Smart Defense & Structure Planning Priority

---

## 🎯 What's New

### 1. Smart Defense System
**Problem**: Unlimited defender spawning caused economic collapse in hostile environments
- Simulation showed 10 defenders vs 1 Source Keeper
- All spawn time consumed by defenders
- No energy for upgraders/builders
- Analytics correctly detected: "Energy declining rapidly"

**Solution**: Intelligent defender caps based on tower availability
```javascript
// Without towers (RCL 1-2)
Max defenders: 3

// With towers (RCL 3+)
Max defenders: 1 (towers handle most threats)

// Economic safety check
If harvesters < 2: Don't spawn any defenders (economy first!)
```

**Impact**: 
- ✅ Prevents defender spam (10 → 1-3)
- ✅ Prioritizes economy over defense when resources low
- ✅ Lets towers handle most combat at RCL 3+

---

### 2. Structure Planning Priority System
**Problem**: Roads filled all 5 construction site slots, blocking critical structures
- Status showed: "0/10 ext, 0/1 tower" despite RCL 3
- Only 13 roads in construction queue
- No extensions/towers/containers being built

**Solution**: Priority-based planning with increased site limit
```javascript
Priority 1: Extensions (energy capacity - CRITICAL)
Priority 2: Towers (defense - CRITICAL at RCL 3+)
Priority 3: Containers (economy boost)
Priority 4: Storage (game-changer at RCL 4+)
Priority 5: Roads (nice to have, placed when <5 sites)
```

**Site limit increased**: 5 → 10 sites allowed for critical structures

**Impact**:
- ✅ Extensions built first (energy capacity increases)
- ✅ Towers built immediately at RCL 3
- ✅ Roads don't block important construction
- ✅ Faster infrastructure development

---

### 3. Enhanced Debug Tools
**Problem**: Simulation testing difficult without detailed diagnostics

**Solution**: Three new console commands

#### `debug()`
Comprehensive simulation diagnostics:
- ✅ Room state (RCL, controller progress)
- ✅ Source count and locations (discovered simulation has 4 sources!)
- ✅ Structure inventory (spawns, extensions, towers, containers)
- ✅ Construction site breakdown by type
- ✅ Hostile details (owner, body parts, position)
- ✅ Creep distribution by role
- ✅ Energy capacity
- ✅ Memory engine state

#### `planStructures()`
Force structure planning (bypasses 100-tick throttle):
- ✅ Immediately runs planner for all rooms
- ✅ Shows what was queued
- ✅ Useful for testing RCL transitions

#### `killAll(role)`
Bulk creep removal:
- ✅ Quick cleanup for testing scenarios
- ✅ Example: `killAll("defender")` removes all defenders
- ✅ Enables rapid iteration

## 📝 Version Tracking

**Why subversion numbers matter:**
- Screeps GUI shows `Memory.engine.version`
- Helps identify which code is running (production vs simulation)
- Critical for debugging: "Is this the old code or new code?"
- Enables A/B testing between environments

**Version Format**: `MAJOR.MINOR.PATCH`
- **2**: v2.0 performance overhaul complete
- **0**: No new features yet (still Phase 1)
- **1**: First patch (defense + structure planning fixes)
